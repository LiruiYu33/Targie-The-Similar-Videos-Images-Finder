# Targie 5.1

## English

Targie 5.1 recalibrates similarity scores so unrelated files no longer appear moderately similar, and fixes how the app is built so it uses the current macOS interface style.

- Similarity scores now discount the baseline that unrelated photos share. In our calibration set, the median score for unrelated images fell from about 41% to about 10%, while resized, recompressed and re-encoded copies of full-size photos still score above 92%.
- Lowering the threshold below the 88% default is now much less likely to group unrelated photos.
- Vision and perceptual-hash evidence are weighted equally, and perceptual-hash agreement alone still cannot override visibly different content.
- Previously cached comparison results are recalculated automatically, so the first scan after updating may take longer. Fast video mode is unchanged.
- The app is now linked against the current macOS SDK, so it uses the system's current interface style instead of a legacy appearance.

Scores indicate visual similarity, not the probability that files are duplicates; review files before deleting them. All seven interface languages remain supported. Requires macOS 14 or later; the universal app supports Apple Silicon and Intel Macs.

## Español

Targie 5.1 recalibra las puntuaciones de similitud para que los archivos no relacionados ya no parezcan moderadamente similares, y corrige la forma en que se compila la aplicación para que utilice el estilo de interfaz actual de macOS.

- Las puntuaciones descuentan ahora la similitud de base que comparten las fotos no relacionadas. En nuestro conjunto de calibración, la puntuación mediana de imágenes no relacionadas bajó de alrededor del 41 % a alrededor del 10 %, mientras que las copias redimensionadas, recomprimidas o convertidas de fotos a tamaño completo siguen superando el 92 %.
- Bajar el umbral por debajo del 88 % predeterminado ya es mucho menos propenso a agrupar fotos no relacionadas.
- Las características de Vision y el hash perceptual tienen ahora el mismo peso, y la coincidencia del hash perceptual por sí sola sigue sin poder imponerse a un contenido visiblemente distinto.
- Los resultados de comparación almacenados en caché se recalculan automáticamente, por lo que el primer análisis tras actualizar puede tardar más. El modo rápido de vídeo no cambia.
- La aplicación se enlaza ahora con el SDK actual de macOS, por lo que usa el estilo de interfaz actual del sistema en lugar de una apariencia antigua.

Las puntuaciones indican similitud visual, no la probabilidad de que los archivos sean duplicados; revísalos antes de eliminarlos. Se mantienen los siete idiomas de la interfaz. Requiere macOS 14 o posterior; la aplicación universal admite Macs con Apple Silicon e Intel.
