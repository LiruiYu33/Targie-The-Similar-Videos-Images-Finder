# Targie 5.2

## English

Targie 5.2 makes reviewing similar files faster and smoother, with drag selection, Finder-style keyboard shortcuts and a more responsive interface.

- Drag to select several cards in a similar group or several rows in Browse. Hold Shift to add to the selection or Command to toggle it; the list scrolls when you drag to its edge.
- Double-click a card to open Preview & Details.
- In Browse, press Command-F to search. Press Command-Delete to delete the selection; in the prompt, press Space to move files to the Trash, or Return and then Return again to delete them permanently.
- Panels, groups and cards now animate smoothly, cards lift on hover and checked cards show a badge. Reduce Motion is respected.
- Switching groups and entering or leaving Browse are noticeably faster, and the sidebar keeps its state when you return from Browse.
- Preview actions have a cleaner layout, and switching groups no longer makes the scroll bar flicker.

All seven interface languages remain supported. Requires macOS 14 or later; the universal app supports Apple Silicon and Intel Macs.

## 한국어

Targie 5.2는 드래그 선택, Finder와 같은 키보드 단축키, 더 빠른 반응으로 유사한 파일을 더 빠르고 부드럽게 검토할 수 있게 합니다.

- 유사 그룹에서는 드래그로 여러 카드를, Browse에서는 여러 행을 선택할 수 있습니다. Shift 키를 누르면 선택에 추가하고 Command 키를 누르면 선택을 전환하며, 목록 가장자리로 드래그하면 자동으로 스크롤됩니다.
- 카드를 이중 클릭하면 미리 보기 및 상세 정보가 열립니다.
- Browse에서 Command-F를 누르면 검색할 수 있습니다. Command-Delete를 누르면 선택 항목을 삭제할 수 있으며, 확인 창에서 스페이스를 누르면 휴지통으로 이동하고 Return 키를 두 번 누르면 영구 삭제합니다.
- 패널, 그룹, 카드가 부드럽게 애니메이션되고, 포인터를 올리면 카드가 떠오르며, 선택한 카드에는 표시가 나타납니다. '동작 줄이기' 설정을 따릅니다.
- 그룹 전환과 Browse 진입·종료가 눈에 띄게 빨라졌고, Browse에서 돌아와도 사이드바 상태가 유지됩니다.
- 미리 보기 작업 버튼이 더 깔끔하게 배치되었으며, 그룹을 전환할 때 스크롤 막대가 더 이상 깜박이지 않습니다.

7개 인터페이스 언어를 모두 계속 지원합니다. macOS 14 이상이 필요하며, 유니버설 앱은 Apple Silicon 및 Intel Mac을 지원합니다.
