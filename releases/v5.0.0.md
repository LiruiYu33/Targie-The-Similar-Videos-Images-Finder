# Targie 5.0

## English

Targie 5.0 improves the native macOS interface for reviewing similar photos and videos, with clearer navigation and more convenient selection and deletion.

- Right-click a card in a similar group, or an item in Browse, to select all displayed files or delete the current selection. A normal click returns to single selection.
- Show or hide Preview & Details as needed, and drag the divider to adjust the comparison and preview widths.
- Comparison cards adapt to the available width. Narrow windows use a single column; long filenames and paths wrap in the details panel, and action controls stack when space is limited.
- Folder and result navigation is simpler, with clearer file information and selection controls.
- Similarity scoring is unchanged. Scores indicate visual similarity, not the probability that files are duplicates; review files before deleting them.

All seven interface languages remain supported: English, Simplified Chinese, Traditional Chinese, Spanish, French, Japanese and Korean. Requires macOS 14 or later; the universal app supports Apple Silicon and Intel Macs.

## Español

Targie 5.0 mejora la interfaz nativa de macOS para revisar fotos y vídeos similares, con una navegación más clara y opciones más cómodas para seleccionar y eliminar archivos.

- Haz clic con el botón derecho en una tarjeta de un grupo similar o en un elemento de Browse para seleccionar todos los archivos mostrados o eliminar la selección actual. Un clic normal vuelve a la selección individual.
- Muestra u oculta la vista previa y los detalles cuando lo necesites, y arrastra el separador para ajustar la anchura de los paneles de comparación y vista previa.
- Las tarjetas se adaptan al ancho disponible. Las ventanas estrechas utilizan una sola columna; los nombres y las rutas largos se distribuyen en varias líneas en el panel de detalles, y los controles se apilan cuando falta espacio.
- Navegación por carpetas y resultados más sencilla, con información de archivos y controles de selección más claros.
- El cálculo de similitud no cambia. Las puntuaciones indican similitud visual, no la probabilidad de que los archivos sean duplicados; revísalos antes de eliminarlos.

Se mantienen los siete idiomas: inglés, chino simplificado, chino tradicional, español, francés, japonés y coreano. Requiere macOS 14 o posterior; la aplicación universal admite Macs con Apple Silicon e Intel.

## Français

## 日本語

Targie 5.0 では、類似した写真や動画を確認するための macOS ネイティブ UI を改善し、ナビゲーションを分かりやすく、ファイルの選択と削除を使いやすくしました。

- 類似グループのカードや Browse の項目を右クリックすると、表示中のファイルをすべて選択したり、選択したファイルを削除したりできます。通常のクリックで単一選択に戻ります。
- 必要に応じてプレビューと詳細を表示・非表示にでき、区切り線をドラッグして比較領域とプレビュー領域の幅を調整できます。
- 比較カードは利用可能な幅に合わせて配置されます。狭いウインドウでは 1 列表示となり、詳細の長いファイル名やパスは折り返され、スペースが足りない場合は操作ボタンが縦に並びます。
- フォルダと結果のナビゲーションを簡素化し、ファイル情報と選択操作を分かりやすくしました。
- 類似度の計算方法は変更していません。スコアは見た目の類似度を示し、重複ファイルである確率ではありません。削除前にファイルを確認してください。

英語、簡体字中国語、繁体字中国語、スペイン語、フランス語、日本語、韓国語の 7 言語に引き続き対応しています。macOS 14 以降が必要です。ユニバーサルアプリは Apple Silicon と Intel の Mac に対応しています。
